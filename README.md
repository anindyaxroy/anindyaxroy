I'm a Principal Consultant at Infosys, where I co-founded an Intelligent Process Automation Centre of Excellence, and I'm completing an Executive MBA in AI & Analytics at the University of Amsterdam.

My current focus is a simple question: **can an autonomous agent be trusted to improve a business process?** My answer so far is yes, if every recommendation is computed from real data, traceable to evidence, and approved by a human.

## Featured project

### [BPMN Agentic Orchestration Validation Platform](https://github.com/anindyaxroy/AgenticOrchestrationValidationPlatform)

A reinforcement-learning agent that learns from process-mining findings on real BPMN event logs and produces process-optimisation recommendations under human-in-the-loop oversight.

- Six-stage disclosed pipeline from event log to recommendation
- Every number is computed from the uploaded file, nothing is hardcoded
- Reasoning is grounded in retrievable evidence rather than free-form LLM output
- Runs locally or as a full Docker stack
